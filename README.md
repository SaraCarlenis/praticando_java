# ☕ Praticando Java

Repositório criado para registrar meus estudos, exercícios e práticas de **Java**, acompanhando minha evolução no desenvolvimento de software.

Este projeto reúne exercícios práticos desenvolvidos durante meus estudos, com foco na construção de uma base sólida em lógica de programação e nos fundamentos da linguagem Java.

---

## 🎯 Objetivo

Consolidar os fundamentos de Java por meio da prática, desenvolvendo o raciocínio lógico, a capacidade de resolver problemas e evoluindo gradualmente para conceitos mais avançados da linguagem.

Este repositório também representa parte da minha jornada de transição para a área de **Desenvolvimento de Software**, com foco em Java e Back-End.

---

## 📚 Conteúdos praticados

### 🔹 1. Variáveis e tipos de dados
Package: `variaveis/e/tipos`

- Declaração e inicialização de variáveis
- Tipos de dados primitivos
- Manipulação de dados
- Entrada de dados com `Scanner`
- Exibição de informações no console

### 🔹 2. Estruturas condicionais
Package: `condicionais/ifelse`

- Estruturas `if`, `else if` e `else`
- Operadores relacionais
- Operadores lógicos (`&&` e `||`)
- Combinação de múltiplas condições
- Tomada de decisão com base em regras de negócio

**Alguns dos Exercícios práticos são:**
- Verificação de triângulos
- Verificação de compatibilidade para doação de sangue
- Validação de critérios utilizando idade e peso
